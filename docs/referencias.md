# Referencias académicas seleccionadas

Se conservarán las cinco referencias seleccionadas por el equipo. La rúbrica compartida solicita **cuatro o más referencias relevantes de IEEE/ACM**, por lo que mantener las cinco proporciona una referencia adicional.

Cada artículo se incluye por la relación de su contenido con estructuras de datos, recursión, programación funcional o análisis de grafos. No se pretende implementar todos los métodos avanzados que describen.

## [1] Functional Programming with Graphs

**Autor:** Martin Erwig.  
**Año:** 1997.  
**Publicación:** Proceedings of the 2nd ACM SIGPLAN International Conference on Functional Programming (ICFP '97), pp. 52–65. ACM.

**Relación con OrganiTree:** presenta una forma funcional de representar grafos persistentes y describe operaciones de plegado (*fold*) sobre grafos. Es la referencia más directa para fundamentar la relación entre estructuras de grafos y programación funcional.

- [Ficha bibliográfica en DBLP](https://dblp.org/rec/conf/icfp/Erwig97)
- [Publicaciones y resumen del autor](https://web.engr.oregonstate.edu/~erwig/papers/abstracts.html)

## [2] Beyond Trees: Calculating Graph-Based Compilers (Functional Pearl)

**Autores:** Patrick Bahr y Graham Hutton.  
**Año:** 2024.  
**Publicación:** Proceedings of the ACM on Programming Languages, vol. 8, ICFP, pp. 370–394.

**DOI:** [10.1145/3674638](https://doi.org/10.1145/3674638)

**Relación con OrganiTree:** explica cómo extender un enfoque funcional basado en árboles para trabajar con estructuras de código organizadas como grafos. Ayuda a comprender la relación entre árboles, grafos y métodos funcionales de construcción.

## [3] Recursive Program Synthesis using Paramorphisms

**Autores:** Qiantan Hong y Alex Aiken.  
**Año:** 2024.  
**Publicación:** Proceedings of the ACM on Programming Languages, vol. 8, PLDI, artículo 151, pp. 102–125.

**DOI:** [10.1145/3656381](https://doi.org/10.1145/3656381)

**Relación con OrganiTree:** estudia patrones estructurados de recursión para construir programas funcionales. Su contenido sirve como respaldo teórico para comprender diferentes formas de recorrer y procesar estructuras recursivas.

## [4] A Graph-Based Higher-Order Intermediate Representation

**Autores:** Roland Leißa, Marcel Köster y Sebastian Hack.  
**Año:** 2015.  
**Publicación:** Proceedings of the 2015 IEEE/ACM International Symposium on Code Generation and Optimization (CGO), pp. 202–212.

**DOI:** [10.1109/CGO.2015.7054200](https://doi.org/10.1109/CGO.2015.7054200)

**Relación con OrganiTree:** presenta una representación de programas basada en grafos que admite conceptos funcionales y funciones de orden superior. Aporta contexto sobre la representación de relaciones y dependencias entre elementos.

## [5] Evaluation of Graph Analytics Frameworks Using the GAP Benchmark Suite

**Autores:** Ariful Azad, Mohsen Mahmoudi Aznaveh, Scott Beamer, Mark Blanco, Jinhao Chen y colaboradores.  
**Año:** 2020.  
**Publicación:** 2020 IEEE International Symposium on Workload Characterization (IISWC), pp. 216–227.

**DOI:** [10.1109/IISWC50251.2020.00029](https://doi.org/10.1109/IISWC50251.2020.00029)

**Relación con OrganiTree:** compara marcos de trabajo para análisis de grafos y estudia algoritmos como búsqueda en anchura, caminos más cortos y componentes conectados. Sirve como referencia para contextualizar operaciones de análisis estructural.

## Nota sobre el uso de las referencias

Los artículos 1, 2 y 3 se relacionan especialmente con programación funcional y recursión. Los artículos 4 y 5 complementan el fundamento de las representaciones y algoritmos sobre grafos. Algunos métodos de estos trabajos son avanzados y se utilizarán como respaldo conceptual, no como una lista de técnicas que el equipo deba reproducir íntegramente.
